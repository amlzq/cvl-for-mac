# Chinese Variants Linter for macOS

**简体中文** | [English](README.en.md)

中文变体检查器的 macOS 版。常驻菜单栏，在任意应用的输入框中检查中文简繁字形和地区用词是否与目标地区（简体中文、中文（台湾）、中文（香港）、繁体中文）一致，并提供就地替换。

文本只在本机处理，不联网，不上传。

## 特点

- 字形检测（简繁不一致）和地区用词检测（如 软件 / 軟體）。
- 允许词、自定义词组，支持 CSV 和 OpenCC 词条格式导入导出。
- 实时标记、建议浮窗、一键替换；读不到文本的应用可用全局快捷键检查或转换选中文本。
- 默认跳过密码框，可按应用启用或禁用。
